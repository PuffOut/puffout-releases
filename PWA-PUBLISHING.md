# Публикация обновлений PWA

После успешного размещения и проверки новой PWA обновляйте posts/pwa-release.json: версию, номер сборки, отметку Hot-fix для небольших исправлений и фактический список изменений. Push этого файла в main автоматически публикует пост в @PuffOutapp через .github/workflows/pwa-release.yml.

Не меняйте release-файл до подтверждённой публикации приложения. Изменения только в скрипте или документации не создают пост. Повторный ручной запуск с check_only=true проверяет доступ без отправки.

Шаблон добавляет ссылку на PWA, инструкцию для iPhone, правила обновления без удаления приложения и официальный блок обратной связи с https://t.me/PuffOutapp?direct. Секретные коды и названия скрытых тем в постах не раскрываются.

Изменения функций Android и PWA должны совпадать. Если исправление PWA лишь восстанавливает уже существующее поведение APK, это следует явно указать в ченжлоге.
